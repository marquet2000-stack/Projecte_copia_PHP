Descargas e instrucciones de instalación

Elige tu sistema operativo y la versión de PHP que quieres usar:

  • Sistema operativo: Linux, macOS o Windows.
  • Linux: Debian, Fedora, RedHat, Ubuntu, Docker (línea de comandos) o Docker (desarrollo web).
  • Versión de PHP: 8.5, 8.4, 8.3 u 8.2.

Instrucciones (ejemplo: Linux, Debian)

Este método de instalación usa los paquetes que ofrece tu distribución de Linux. Incluyen cambios en el código fuente de PHP añadidos por quien crea el paquete, sobre los que el proyecto PHP no tiene control.

En la línea de comandos, ejecuta lo siguiente:

# Actualizar la lista de paquetes.
sudo apt update

# Instalar PHP.
sudo apt install -y php

Versiones soportadas

Consulta la página de versiones soportadas para saber cuánto tiempo recibe soporte cada versión de PHP.

Otras opciones

También existen opciones para usar varias versiones de PHP a la vez, compilar todo desde el código fuente o consultar las instrucciones de actualización.
