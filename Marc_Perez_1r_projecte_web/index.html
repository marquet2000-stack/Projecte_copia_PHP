PHP 8.6.0 RC7 disponible para pruebas

12 Nov 2026

El equipo de PHP anuncia la quinta versión candidata de PHP 8.6.0, RC7. Por favor, pruébala y comunica cualquier problema en GitHub.

No uses esta versión en producción, es una versión de pruebas.

La próxima versión será la primera GA, PHP 8.6.0, prevista para el 19 de noviembre de 2026.
